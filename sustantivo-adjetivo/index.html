✦ Sustantivo + adjetivo

Учимся ставить прилагательное после существительного: una casa grande · un coche rojo · una chica simpática.

💡 Запомни: для этой практики используем порядок артикль + существительное + прилагательное. Например: un gato negro.

1. 🎯 Elige la opción correcta

Выбери вариант с нужным порядком слов.

2. 🧩 Ordena las palabras

Нажимай на слова в правильном порядке, чтобы составить словосочетание. Чтобы исправить ответ, нажми на выбранное слово.

Пример: grande / una / casa → una casa grande
